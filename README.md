# 📊 2026 iThome 鐵人賽：AI 數據分析教材與互動 QA 學習系統

本專案為參加 **2026 年 iThome 鐵人賽（主題：AI 輔助數據分析）** 之教材發想與輔助學習工具。

## 🎯 專案建置背景與緣起

在籌備 2026 年 iThome 鐵人賽的 30 天挑戰過程中，為了讓讀者與學習者能以更高效率吸收「數據分析核心觀念」、「GenAI 提示詞工程」及「Tableau / Excel 實戰思維」，本專案透過 Anki 問答抽問的概念，將每日文章的核心精華提煉成結構化的問答庫。

為突破傳統文字閱讀的被動吸收限制，本工具可**自動將 `source/` 目錄下的各單元 Anki 來源檔（Tab 分隔問答）批次轉換為現代化的互動式 QA 學習網頁**，提供讀者隨時檢測理解程度、進行翻卡抽考，亦作為作者撰寫教材、梳理知識脈絡與驗證教學內容的發想平台。

---

## 📁 專案目錄結構

```text
├── source/               # 存放 Anki 來源檔（例如 Day1.txt, Day2.txt）
├── html/                 # 產出的各天互動式 QA 網頁（例如 Day1.html, Day2.html）
├── index.html            # 全單元總目錄導覽首頁（相對連結至 html/*.html）
├── convert.js            # Node.js 轉檔核心腳本（零第三方套件依賴）
├── convert.bat           # Windows 一鍵批次執行檔（純 ASCII，雙擊即跑）
├── package.json          # 專案設定檔
└── README.md             # 本說明文件
```

---

## 🚀 快速開始

### 方法 1：Windows 一鍵執行（最推薦）
在 Windows 檔案總管中，直接**雙擊執行 `convert.bat`** 即可自動完成轉檔。

### 方法 2：使用 npm 或 Node 指令
```bash
npm start
# 或直接透過 node 執行
node --preserve-symlinks-main convert.js
```

轉檔完成後，直接於瀏覽器開啟專案根目錄下的 `index.html` 即可開始使用！

## ✨ 核心功能特色

- **檔名完全對應**：`source/Day1.txt` 自動對應輸出至 `html/Day1.html`，乾淨易懂。
- **全單元首頁導覽**：自動於根目錄產出 `index.html`，動態彙整所有天數的問答單元與題目總數。
- **兩種高效率學習模式**：
  - **📋 列表問答模式 (List View)**：點擊題目展開答案、支援全部展開/收合，並可透過搜尋框進行題目與答案全文檢索。
  - **🎴 單卡翻卡抽考 (Flashcard Quiz)**：具備 3D 擬真翻卡動態，支援鍵盤快捷鍵（`Space` 翻面、`←` / `→` 切換題目、`M` 標記掌握）。
- **個人化學習進度記憶**：支援每題星號（★）「掌握度」標記，並可一鍵過濾「⭐ 只看未掌握」，進度自動儲存於瀏覽器 LocalStorage。
- **LaTeX 數學公式美化**：內建 KaTeX 引擎，自動渲染 `$ ... $` 內的數學公式與箭頭符號（如 `$60\%$`、`$\rightarrow$`、`$20240101$`）。
- **純單檔離線相容**：產出的 HTML 整合樣式與邏輯，無須架設伺服器，雙擊即可離線順暢操作。
